feat(stdlib): add pure-Python _lsprof shim and profiling package (cProfile)

cProfile was missing (No module named cProfile), which breaks build
backends like meson-python. RustPython has no C _lsprof module, so:

- Lib/_lsprof.py: pure-Python _lsprof compatible shim built on
  sys.setprofile with CPython timing semantics (totaltime includes
  subcalls, inlinetime excludes them; recursion counted)
- Lib/profiling/ + Lib/cProfile.py: synced from CPython 3.15

Verified: cProfile.Profile output matches CPython structure exactly
(466 function calls, 465/1 recursive fib); cProfile.run() and
pstats.Stats work; profiling.sampling imports cleanly.
