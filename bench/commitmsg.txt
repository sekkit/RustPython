fix(ctypes): return live struct/union instances for array elements

Array elements of structure/union type were decoded as raw integers
(read_array_element has no struct branch), so (Point*3)()[i] returned an
int and pts[i].x = 7 did not work.

When the element type has no primitive type code, build a PyCData
instance backed by the base buffer at the element offset (CPython view
semantics: reads and writes through the element hit the array storage).

Verified: (Point*3) element read/write and write-back work and match
CPython; test_ctypes passes (328 run, 58 skipped).
