feat(capi): PyErr_Format via the C varargs shim

Add PyErr_Format (CPython Python/errors.c), the most-used variadic error
API in real extensions. The C shim snapshots the varargs with a
printf-style slot counter; Rust formats the message (s, d, i, u, o, x,
X, c, p, R, S, U, T, A, V codes with l/ll/h/z/t/j length modifiers;
width/precision accepted) and raises the exception.
