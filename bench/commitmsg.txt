fix(ctypes): support callbacks as function arguments (from_param + conversion)

CFUNCTYPE/WINFUNCTYPE instances could not be passed as arguments to DLL
functions: PyCFuncPtrType lacked from_param, the type_code validation
rejected function-pointer types, and neither conv_param nor
convert_object handled PyCFuncPtr values. EnumWindows(Proc(cb), 0) failed
with TypeError("Unsupported argument type").

- PyCFuncPtrType::from_param: returns the callback instance (CPython
  parity), keeping it alive through the call
- convert_object: exempt function-pointer types from _type_ validation;
  convert PyCFuncPtr to its stored function pointer
- conv_param: convert PyCFuncPtr to a pointer value, keeping the callable
  alive

Verified: EnumWindows with the standard WINFUNCTYPE decorator pattern
enumerates windows (467); test_ctypes passes (328 run, 58 skipped).
