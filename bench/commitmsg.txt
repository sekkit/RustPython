fix(stdlib): extension_suffixes returns platform suffixes; add_dll_directory

- _imp.extension_suffixes() returned an empty list, so extension
  importers (FileFinder) never looked for native modules (.pyd/.dll on
  Windows). Now returns platform-correct suffixes: [".pyd", ".dll"] on
  Windows, [".so"] on Unix, [".so", ".dylib"] on macOS (CPython parity).
- nt._add_dll_directory / _remove_dll_directory were missing, breaking
  os.add_dll_directory which numpy's delvewheel patch calls first.
  Implemented via AddDllDirectory/RemoveDllDirectory (host_env + nt.rs).

Verified: _imp.extension_suffixes() == ['.pyd', '.dll'];
os.add_dll_directory() round-trips with close(). test_importlib and
test_os pass.
