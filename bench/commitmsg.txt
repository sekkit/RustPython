feat(cprofile): monitoring-based _lsprof; sys.monitoring importable; compile() module kwarg

cProfile was unusable: test_cprofile had 8 failures + 10 errors. Root causes
and fixes:

1. `import sys.monitoring` raised `ModuleNotFoundError` -- the submodule was
   built and attached as the `sys.monitoring` attribute but never registered
   in sys.modules under its dotted name. Fixed in sys.rs init_module (CPython
   does the same via PyImport_AddModule("sys.monitoring")); test_monitoring
   88 run green.

2. Lib/_lsprof.py was a minimal sys.setprofile shim: missing clear(), the
   _pystart/_pyreturn/_ccall/_creturn callbacks, sys.monitoring tool
   registration, second-profiler ValueError, and it mis-handled external
   timers. Rewritten as a faithful port of CPython 3.14 Modules/_lsprof.c on
   top of the VM's sys.monitoring: registers tool PROFILER_ID ("cProfile")
   with the 9 events (PY_START/PY_RESUME/PY_THROW/PY_RETURN/PY_YIELD/
   PY_UNWIND/CALL/C_RETURN/C_RAISE), ports the ProfilerContext/Entry/
   SubEntry timing model (initContext/Stop/flush_unmatched), external-timer
   semantics (disable/clear inside a timer raise RuntimeError which surfaces
   as an unraisable; timer errors reported via sys.unraisablehook), and
   normalizeUserObj labels ("<built-in method mod.name>", "<method 'x' of
   'Y' objects>"). The profiler's own enable()/disable() calls surface as
   built-in methods exactly like CPython's C methods, and its internal
   monitoring calls are not self-profiled.

   Result: cProfile output is byte-identical to CPython 3.14's expected
   output (do_profiling print_stats/print_callers/print_callees all match),
   test_cprofile 24/24 green (was 8F+10E); the inherited expectedFailure in
   test_profile.py (still needed for the pure-Python profile.Profile) is
   lifted for CProfileTest via an unmarked wrapper.

3. compile() lacked the keyword-only `module` parameter (used by the
   cProfile script runner): added with CPython's validation
   ("compile() argument 'module' must be str or None, not %T").

Verified: test_cprofile 24, test_profile 7, test_monitoring 88, test_builtin

test_sysconfig 37, test_venv 40, test_signal 57, test_threading 229,
