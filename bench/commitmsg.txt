fix(type): allow __dict__/__weakref__ in __slots__ alongside class attributes

CPython treats __dict__ and __weakref__ as special slots: a class-level
attribute with the same name is not a conflict (the member descriptor
check only applies to ordinary slot names). RustPython rejected this
with ValueError("'__dict__' in __slots__ conflicts with class
variable"), which broke celery's Proxy class (celery/local.py defines
__slots__ containing '__dict__' together with a __dict__ property).

Skip the conflict check for these two special names. Verified: the
celery 5.6.3 pattern now works and matches CPython; ordinary slot/class
variable conflicts still raise ValueError; test_descr passes
(162 run, 18 skipped).
